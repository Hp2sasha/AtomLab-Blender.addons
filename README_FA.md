# AtomLab 0.16.0 — کتابخانهٔ مولکول‌های سفارشی با زیرنویس/بالانویس

افزونه برای Blender 5.2+؛ فایل اصلی افزونه `atomlab_addon.py` است.

## قابلیت‌های افزوده‌شده

- ذخیرهٔ مولکول ساخته‌شده در کتابخانهٔ JSON داخل پروژهٔ `.blend` و کتابخانهٔ مشترک محلی.
- ذخیرهٔ نام، شناسهٔ پایدار، فرمول، مختصات سه‌بعدی، عنصر، بار رسمی، پیوندها، مرتبهٔ پیوند، بار خالص و یادداشت.
- ساخت دوبارهٔ مولکول از کتابخانه، import/export فایل JSON و کنترل نسخهٔ schema.
- برخورد نام/شناسه به‌طور پیش‌فرض رد می‌شود؛ جایگزینی فقط با فعال کردن گزینهٔ صریح در UI انجام می‌شود.
- نوشتن دوگانه با rollback جبرانی در صورت شکست یکی از نوشتن‌ها.
- در نام/یادداشت کتابخانه از `_2` برای زیرنویس و `^2-` یا `^{3+}` برای بالانویس استفاده کنید؛ پیش‌نمایش و فهرست انتخاب، نویسه‌های درست Unicode را نشان می‌دهند و JSON نشانه‌گذاری ساده را نگه می‌دارد.

## نصب

در Blender از **Edit → Preferences → Add-ons → Install from Disk** فایل `atomlab_addon.py` را انتخاب و افزونه را فعال کنید. پنل در **View3D → Sidebar → AtomLab** قرار دارد.

در بخش **My Molecule Library** نام و یادداشت را وارد کنید و **Save molecule** را بزنید. برای بازسازی، از فهرست مولکول ذخیره‌شده انتخاب کنید و **Create from library** را بزنید. برای انتقال کتابخانه از دکمه‌های Import JSON و Export JSON استفاده کنید.

فایل داخل پروژه با نام `AtomLab_Custom_Molecules.json` در Blender Texts ذخیره می‌شود؛ برای ماندگاری نهایی پروژه، فایل `.blend` را ذخیره کنید. کتابخانهٔ مشترک در پوشهٔ پیکربندی کاربر Blender، زیر `atomlab/custom_molecules.json` قرار می‌گیرد.

## آزمون‌ها

- `tests/test_custom_molecule_schema.py` — آزمون مستقل اعتبارسنجی schema، فرمول، بارها، هندسه، پیوندها و سیاست برخورد.
- `tests/blender_custom_molecule_smoke_test.py` — آزمون یکپارچهٔ Blender 5.2.4، شامل ذخیره/بازگشایی `.blend`، بازسازی هندسه و JSON مشترک.

آزمون‌های اجراشده در این بسته: هر دو آزمون بالا، به‌علاوهٔ regression suite دوازده الگوی یونی؛ همگی موفق.
