# AtomLab — افزونهٔ آموزشی Blender

**نسخه:** 0.16.0  
**نسخهٔ هدف:** Blender 5.2 و بالاتر  
**نوع پروژه:** پروژهٔ درسیِ واحد آزمایشگاه نرم‌افزار دانشگاه

> **یادداشت دربارهٔ ماهیت پروژه**  
> AtomLab صرفاً به‌عنوان پروژه‌ای آموزشی برای ارائه و ارزیابی در واحد آزمایشگاه نرم‌افزار دانشگاه تهیه شده است. این کار یک نمونهٔ اولیهٔ درسی است؛ نه نرم‌افزار آمادهٔ استفادهٔ حرفه‌ای، نه ابزار علمیِ تأییدشده، و نه محصول رسمی دانشگاه یا بنیاد Blender. نمایش‌های علمی آن ساده‌سازی‌شده و شماتیک‌اند و نباید به‌عنوان دادهٔ تجربی، پژوهشیِ دقیق یا ایمنی‌حساس استفاده شوند.

## معرفی

AtomLab یک افزونهٔ Blender برای ساخت و بررسی نمایش‌های سه‌بعدی آموزشی از مدل اتم، شکل‌های ساده‌شدهٔ احتمال اوربیتال‌های کوانتومی، قطعه‌های شبکهٔ بلورهای یونی، و مولکول‌های ساخته‌شده توسط کاربر است.

محدودیت‌های آموزشی در رابط افزونه مشخص می‌شوند: هندسه‌ها می‌توانند ایده‌آل‌شده باشند، بارها صوری‌اند و اندازه‌ها شماتیک هستند. ساختار یونی به‌شکل قطعه‌ای از شبکهٔ گسترده نمایش داده می‌شود و میله‌های پیوند کووالانسی میان یون‌ها القا نمی‌شوند.

## قابلیت‌ها

- نمایش شماتیک اتم و هسته، همراه با نمایش ساده‌شدهٔ شکل احتمال برخی اوربیتال‌های کوانتومی.
- مجموعه‌ای قابل‌گسترش از الگوهای بلور یونی، به‌صورت قطعهٔ شبکه.
- سازندهٔ تعاملی مولکول با انتخاب عنصر، بار رسمی، پیوند و مرتبهٔ پیوند.
- کتابخانهٔ ماندگار مولکول سفارشی، هم داخل فایل پروژهٔ `.blend` و هم در فایل JSON محلیِ مشترک.
- واردکردن و صادرکردن JSON نسخه‌دار برای انتقال داده‌ها.
- اعتبارسنجی رکوردها و محافظت در برابر جایگزینی ناخواستهٔ نام یا شناسه.
- نشانه‌گذاری زیرنویس و بالانویس برای نام و یادداشت کتابخانه:
  - `H_2O` به‌شکل H₂O نمایش داده می‌شود.
  - `SO_4^2-` به‌شکل SO₄²⁻ نمایش داده می‌شود.
  - `Fe^{3+}` به‌شکل Fe³⁺ نمایش داده می‌شود.

## نصب

1. در Blender مسیر **Edit → Preferences → Add-ons** را باز کنید.
2. از منوی گوشهٔ بالا سمت راست بخش Add-ons، گزینهٔ **Install from Disk…** را بزنید.
3. فایل `atomlab_addon.py` را انتخاب و سپس AtomLab را در فهرست افزونه‌ها فعال کنید.
4. در نمای سه‌بعدی کلید **N** را بزنید و تب کناری **AtomLab** را انتخاب کنید.

## کتابخانهٔ مولکول سفارشی

در بخش **Interactive molecule builder** اتم‌ها را اضافه کنید، بار رسمی را تعیین کنید و پیوندها را بسازید. در بخش **My Molecule Library** نام و یادداشت اختیاری را وارد و مولکول را ذخیره کنید.

هر رکورد شناسهٔ پایدار، نام، فرمول محاسبه‌شده، عنصر و مختصات سه‌بعدی اتم‌ها، بار رسمی هر اتم، دو سر و مرتبهٔ پیوندها، بار خالص و یادداشت را نگه می‌دارد. برخورد نام یا شناسه به‌طور پیش‌فرض رد می‌شود؛ جایگزینی فقط با اجازهٔ صریح انجام می‌شود.

نسخهٔ پروژه‌ای در Blender Text با نام `AtomLab_Custom_Molecules.json` ذخیره می‌شود؛ برای نگه‌داشتن آن فایل `.blend` را ذخیره کنید. کتابخانهٔ مشترک در پوشهٔ پیکربندی کاربر Blender، در مسیر `atomlab/custom_molecules.json`، قرار دارد. برای انتقال داده‌ها از دکمه‌های JSON در پنل استفاده کنید.

نشانه‌گذاری زیرنویس و بالانویس به‌شکل متن ساده ذخیره می‌شود و در پیش‌نمایش و فهرست انتخاب به نویسه‌های مناسب تبدیل می‌شود. برای زیرنویس از `_` و برای بالانویس از `^` استفاده کنید؛ آکولاد می‌تواند گروه را مشخص کند، مانند `^{3+}`.

## آزمون‌ها

آزمون‌های مستقل از Blender را از ریشهٔ مخزن اجرا کنید:

```sh
python tests/test_custom_molecule_schema.py
python tests/test_ionic_structures.py
```

آزمون‌های یکپارچه را با Blender 5.2 یا بالاتر اجرا کنید:

```sh
blender -b --factory-startup --python tests/blender_custom_molecule_smoke_test.py
blender -b --factory-startup --python tests/blender_ionic_smoke_test.py
```

آزمون مولکول سفارشی ثبت افزونه، اعتبارسنجی، ورود/صدور JSON، ذخیرهٔ پروژه‌ای و ماندگاری پس از بازگشایی `.blend` را بررسی می‌کند. آزمون یونی را فقط در صحنهٔ موقت اجرا کنید و پیش از اجرای تعاملی، راهنمای داخل فایل آزمون را بخوانید.
